# 图寻照片棋盘

本页沿用 MASTER 的竞赛控制台、方圆字体及任务/道具与定位两栏结构。玩家仅显示后台已审核的本队当前区域，区域进度标记只读；不得自行浏览过去或未来区域，也不得通过参数或区域按钮换图。

- 使用此前共享图寻配置的既定 5×5 格位，P01–P19 对应照片编号 #1–#19，D01–D06 为无需图寻的任务。
- 三个区域共 57 张不同的编号成品。照片资源不绑定队伍，任务 ID、提交和完成状态不随共用图片合并。
- 每队独立推进：下一地区入口图寻提交进入 FIFO 队列，工作人员审核通过后，由后台更新该队当前区域；提交、待审核、打回、普通任务通过都不能换区。只允许按 1→2→3 推进，不跳区或倒退；审核必须含 teamId 和 targetRegionId。
- 更新当前区域时，玩家可浏览的五张Bingo中的19个图寻格统一按本队区域重新映射，同一格仍是相同编号；每张的6个直接任务、共125项任务的ID、内容、分数与完成/审核状态保持不变。旧区详情与上传草稿关闭，以免错交。
- 本机现有 React 程序仍为前端交互原型。`reviewAudit` 演示审核事务与按队推进，`approvedRegionId` 是 PlayerApp 的只读输入。生产后端须执行鉴权、持久化、去重、版本校验并实时发送该队最新状态；前端不得成为权威来源。
- 格子中只显示模糊照片、编号、分值与状态；任务文案和清晰图片只能在点开格子后显示。悬停不得去除模糊。
- 模糊由两层固定 blur 的纹理通过 opacity/transform 交叉渐变实现，不逐帧重新计算 blur。入场最多运行两轮；用户可暂停，减少动态模式、页面后台、格子键盘聚焦或任何弹窗打开时停止。
- 480px WebP 仅用于模糊预览；清晰详情使用最大1800px WebP并保持完整比例，不裁线索。可另开带编号的原尺寸 PNG。原始照片、编号成品及现有演示文案保持不覆盖。
- 新增的任务格没有正式文案时明确“待配置”，不开放提交，不把暂存的0分当作正式分值展示。
- 验证：手机375px、横屏812px、平板768px及桌面1440px；始终5列，按钮至少44px，页面无横向溢出。保持既有登录/等待页规则。
