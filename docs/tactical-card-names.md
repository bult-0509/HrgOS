# 战术道具卡名称

沿用项目已写好的功能与名称。完整规则、时限、目标和奖惩统一保存于 src/data/abilityCatalog.json；正式后端和本地卡面共用，随机发卡机制不变。

| 编号 | 卡名 | 原功能 |
|---|---|---|
| 1 | 合照换分 | 与对方碰面并合照，经工作人员确认后交换双方当前总积分。 |
| 2 | 原地冻结 | 指定队伍保持位置不移动 5 分钟。 |
| 3 | 排名透视 | 立即查看全体队伍积分和排名，持续 10 分钟。 |
| 4 | 微笑朗诵 | 指定队伍停下，一位成员微笑面对镜头完成诗朗诵或演讲，否则扣 100 分。 |
| 5 | 榜首援助 | 当前积分最高的队伍立即给本队 100 分。 |
| 6 | 下蹲挑战 | 指定队伍所有成员两分钟内各完成 20 个下蹲，每缺一个扣 25 分。 |
| 7 | 三足限制 | 指定队伍五分钟内同时落地的脚必须少于四只。 |
| 8 | 双手许可 | 接下来的一个任务可使用双手，任务审核通过后消耗许可。 |
| 9 | 循环唱词 | 除自身外所有队伍两分钟内持续重复 only feels like nothing could be better when Im with you，违者扣 50 分。 |
| 10 | 五字交流 | 指定队伍五分钟内只能五个字五个字地交流。 |
| 11 | 期末周饮品 | 指定队伍五分钟内前往最近的超市购买一瓶期末周饮品。 |
| 12 | 任务重演 | 指定队伍重做最近完成的任务，完成可获得原任务一半积分。 |
| 13 | 最难曲 | 指定队伍停下立即游玩一首最难曲，三分钟未完成扣 50 分。 |
| 14 | 时空回返 | 指定队伍实际返回十分钟前的真实位置，由工作人员确认。 |
| 15 | 任务交换 | 指定队伍选择另一支队伍，交换双方接下来要做的任务。 |
| 16 | 持续接触 | 指定队伍十分钟内所有成员持续保持肢体接触。 |
| 17 | 贴地行走 | 指定队伍移动时双脚不能同时离地，持续十分钟。 |
| 18 | 单手游戏 | 指定队伍十分钟内所有成员只能单手操作游戏。 |
| 19 | 隐匿追逐 | 本队十五分钟内不被其他队伍接触即可加分，其他队伍可查看本队实时位置。 |
| 20 | 昵称拼词 | 随机队伍用三位成员的昵称拼出 hrg 或 awmc，成功加分，失败扣分。 |
| 21 | 圆周率接力 | 所有队伍三人协力三十秒内背诵圆周率，背出的小数位数即加分数。 |
| 22 | 第九章密钥 | 所有队伍在输入框提交第九章密钥，正确答案中最快队伍加分、最慢队伍扣分。 |
| 23 | 无中生有 | 指定队伍从未抽到的备用任务中随机抽取一项，十五分钟内完成并提交证据。 |
| 24 | 爆裂魔法 | 指定队伍所有成员禁言五分钟，只能使用手机打字交流。 |

项目当前仅有 24 张，第 25 张尚未找到既定定义，不添加自创占位规则。
