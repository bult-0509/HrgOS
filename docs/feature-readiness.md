## 已复测的结果

| 要求 | 正式页面现状 | 隔离后端现状 | 结论 |
| --- | --- | --- | --- |
| 工作人员随机事件发放、现场创作 | “抽取”“确认发放”点击无变化，没有创建表单 | 预设事件抽取、加分和队伍收件通过；只有一种预设测试事件，自创接口缺失 | 未完成 |
| 动效优化 | 图片雾层动效、窗口进出等已存在；暂停按钮原来未真正停止雾层动画 | HTTP 无法判断帧率和耗电 | 暂停 bug 已修复并浏览器复测；手机性能待测 |
| 图片/文本发送给工作人员 | 图片只把文件名传入本页状态，另一页面的工作人员收不到；文本发送入口不存在 | 图片入队和工作人员读取原图通过；文本发送接口缺失 | 正式跨设备收件未完成 |
| 定位实时跟踪和记录 | 展示固定示意坐标，未接入 `createLocationReporter`、GPS 或真实接口 | 三次合成坐标更新、工作人员读取、六十秒轨迹采样通过；既有测试验证重启持久化 | 后端规则通过，正式定位功能未接入 |
| 看最低队伍并发送特殊挑战 | 可查看演示分数表，没有最低队伍识别/挑战发送入口 | 可从工作人员视图识别唯一最低分队伍；特殊挑战发送接口缺失 | 未完成 |
| 区域完成自动发能力卡 | 卡牌是演示初始库存，没有完成区域发卡逻辑 | 本区五项任务完成后新增区域奖励卡为 0；三张测试初始卡不算奖励 | 未完成 |

正式页面浏览器操作验证了工作人员事件按钮无变化。另在玩家页选择合成测试 PNG 并点击提交，本页显示提交成功；检查调用后确认仅记录文件名和本地队列，未上传文件。已将这个误导提示改为“仅本地演示”，明确工作人员设备不会收到。

动效的暂停 bug 原因是 `.photo-preview.is-visible .photo-preview__haze` 的动画简写规则优先级更高，覆盖暂停规则的 `animation-play-state`。修复后浏览器读取计算样式：暂停时 `paused`，恢复时 `running`；模拟系统 `prefers-reduced-motion: reduce` 后动画名为 `none`，测试后已恢复媒体设置。真实手机帧率、耗电与锁屏行为尚未测试。

## 再次执行

```powershell
npm run test:lab
```

打开测试 URL、输入密钥，点击新增的 **专项功能验收**。也可命令行：

```powershell
npm run test:readiness:local
```

本次结果：**3 项通过、4 项失败、2 项待人工验收**。命令行有未实现的功能时返回非零退出码，并生成 `artifacts/feature-readiness-report.json`。这表示功能不满足验收要求，不能为了变绿而删掉失败项。

`runFeatureReadiness` 经真实 HTTP 建立独立赛局、创建随机账号、提交与审核图片、发放预设事件、更新并读回位置、完成五项任务、识别最低分队伍，最后清理赛局。坐标和图片均为合成测试数据，报告不含账号密码或经纬度。

尚未实现的功能采用明确的验收命令契约：`event_create`（现场创作）、`send_message`（文本收件）、`send_challenge`（特殊挑战）。当前后端均返回 `HTTP 400 COMMAND_UNKNOWN`，与源代码不存在对应实现相符。后续实现如改用其他接口，需同步更新验收契约，并保留“保存后能从接收方读回完整内容”的断言。卡牌检查采用本区现有五项计分上限作为完成边界；正式完成条件、奖励卡池、同分最低队伍规则需在实现时配置，不能直接把该测试约定当作完整业务设计。

连接部署后的异地 PostgreSQL：

```powershell
$env:HRG_TEST_API_URL = 'https://hrgos.skyseiun.com'
$env:TEST_API_KEY = '由部署人员在本机环境中配置的密钥'
npm run test:readiness
```

后端报告必须显示 `postgresql` 才能证明测的是异地数据库。本次没有服务器权限与远端测试密钥，结果来自本机 PostgreSQL WASM 验证；不能声称异地部署或真实手机定位已经通过。

## 尚需实现的链路

正式页面接入鉴权 API 和实时通道；工作人员创建/编辑事件、确认发放与玩家收件；图片原文件与文本提交、工作人员收件和回执；队长前台定位上报、工作人员地图和轨迹展示；最低队伍识别、特殊挑战下发与完成审核；区域完成的明确判定、奖励卡池和事务内唯一发卡。能力卡完整效果与使用限制也需要按正式规则配置并验收。

入口代码：`src/testing/featureReadiness.ts`。主页面当前行为位于 `src/DemoApp.tsx`、`src/staff/StaffApp.tsx`、`src/player/PlayerApp.tsx`；沙箱规则位于 `server/rules.mjs`。
